# README 像素风示例图更新记录

日期：2026-05-19

## 背景

照片类输入即使经过平滑、限色和清理，仍容易在皮肤、背景和阴影处产生脏块。拼豆图纸更适合轮廓清晰、色块稳定、主体占比高的像素风或 Q 版图像，因此 README 示例改用 Koishi 和 Marisa 两张像素风图。

## 选图结论

候选图在本地生成预览和符号图后做了视觉筛选：

| 样例 | 网格 | 颜色数 | 观察 |
| --- | --- | --- | --- |
| Koishi | 48x48 | 22 | 全身轮廓完整，衣服、帽子和道具的主色块清楚，适合展示透明背景和小色块清理。 |
| Marisa | 58x33 | 18 | 横向头像构图适合 README 表格，帽子、头发、背景分层清楚，色块比照片输入更干净。 |

## 参数记录

README 资产由 `examples/build_readme_images.py` 生成：

- `fit="contain"`：保留完整构图。
- `background="transparent"`：透明区域不参与用豆数量和符号图。
- `resample="box"`：比 `nearest` 更不容易在非整数缩放时丢线，比 `lanczos` 更少产生像素图边缘混色。
- `quantize="nearest"`、`color_space="lab"`：避免抖动造成棋盘纹理，同时使用感知距离做最近色。
- `cleanup="majority"`、`cleanup_passes=1`、`min_region_size=2`：减少单点孤岛，但不过度抹掉像素图线条。
- Koishi 使用 48x48、最多 22 色；Marisa 使用 58x33、最多 18 色。

## 后续行动

- README 示例继续优先使用清晰像素图或 Q 版图，而不是三次元照片。
- 如果后续加入更强的自动像素化或主体分割流程，可以用同一批示例图做前后对比。
- 照片类示例应放到单独文档中说明参数取舍，不作为 README 第一视觉示例。
